# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome people of every background and level of experience, and focus on
what is best for the work and the people doing it. Harassment, insults and personal attacks are not accepted.

Report unacceptable behaviour to the maintainer through a private message on GitHub (profile linked from the
repository). Reports are handled confidentially; the maintainer may remove comments, commits or contributions that do
not follow this code.
